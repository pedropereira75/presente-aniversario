# Presente de aniversário ❤️

Um site romântico em preto e vermelho, feito com HTML, CSS e JavaScript puro. Não precisa de servidor, banco de dados ou instalação de dependências.

## Como executar
1. Extraia o ZIP para uma pasta.
2. Abra `index.html` no navegador.
3. Para desenvolver, abra a pasta no VS Code. Você pode usar a extensão **Live Server**, mas não é obrigatório.

## Personalize antes de enviar
- **Perguntas do quiz:** abra `script.js` e edite a lista `questions`.
- **Presente da raspadinha:** em `index.html`, procure `id="giftText"` e troque o texto.
- **Carta final:** em `index.html`, edite os parágrafos dentro de `<article class="letter">`.
- **Nome dela:** você pode acrescentar o nome no título ou na carta.
- **Cores:** em `style.css`, altere as variáveis dentro de `:root`.

Sugestão: troque o presente genérico por algo que você realmente possa oferecer, como um encontro escolhido por ela ou uma noite de filme e comida favorita.

## Publicar grátis com GitHub Pages
1. Crie ou entre em sua conta em [github.com](https://github.com/).
2. Crie um repositório público, por exemplo `presente-aniversario`.
3. Envie os três arquivos (`index.html`, `style.css`, `script.js`) e este README para o repositório.
4. No repositório, entre em **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
7. Aguarde alguns minutos. O GitHub mostrará o endereço público na mesma seção. Abra esse endereço no celular para testar e então envie o link.

## Alternativa: Netlify
Acesse [netlify.com](https://www.netlify.com/), crie uma conta e use a opção de publicar manualmente uma pasta/site estático. Arraste a pasta que contém os arquivos para a área de deploy indicada pela plataforma. Use o link gerado para testar e compartilhar.

## Observações
- O site não coleta nem envia dados: as respostas ficam apenas na página durante a visita.
- A fonte decorativa é carregada do Google Fonts; se não houver internet, haverá fontes alternativas.
- Teste o link no celular antes de enviar.
